# 5-person test of the ShopRank page (about 5 minutes per person)

Page: https://shoprank-jasirjru.vercel.app
People: 5 in total, ideally 2 recruiters or HR people, 2 engineers, 1 non-technical person. Test one at a time,
on their own phone or laptop. Do not explain the page before or during the test.

Pass rules (written before testing):
- 5-second test: at least 4 of 5 say what ShopRank does AND that it beats keyword search.
- Task: at least 4 of 5 find proof that it is real in under 1 minute.

## Script (read it out word for word)

1. "I'll show you a web page for 5 seconds, then hide it." Open the page, count 5 seconds, hide it.
2. Ask: "What does this project do?" Write down their words.
3. Ask: "Is it better or worse than something else? Than what?" Write down their words.
4. Show the page again. "Please find proof that this really works. Think out loud while you look."
   Start a timer. Stop when they point at real proof (an example list, the scores, the code or the model link).
5. Ask: "Was any word or sentence confusing?" Write down each one.
6. Ask: "Would you open the GitHub code from here? Why or why not?"
